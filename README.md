# 🚀 ResumeAI – Intelligent Resume Analysis & Career Guidance Platform

ResumeAI is an AI-powered resume analysis platform that helps students and job seekers evaluate their resumes, improve ATS compatibility, identify skill gaps, receive personalized career guidance, and generate professional portfolio websites.

Built using **HTML, CSS, JavaScript, and Python (Flask backend)**, ResumeAI provides a modern, responsive interface with secure AI integration and an intuitive user experience.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/gmedhareddy/Resume-Analyzer-.git
```

Go into the project

```bash
cd Resume-Analyzer-
```

Install Python packages

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```

Open

```
http://localhost:5000
```

---

# 🔑 Environment Variables

Create a `.env` file

```
CLAUDE_API_KEY=your_api_key

OPENAI_API_KEY=your_api_key

GEMINI_API_KEY=your_api_key
```

Never commit your API keys to GitHub.
